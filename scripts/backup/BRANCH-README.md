ไฟล์จึงถูกล็อกด้วยกุญแจที่มีแค่เจ้าของโรงงานถือ (`po-tracker-backup-key.txt`) — **ถ้ากุญแจหาย จะเปิดไฟล์เหล่านี้ไม่ได้อีกเลย**
