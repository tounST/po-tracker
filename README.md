## 📂 ในนี้มีอะไรบ้าง

### หน้าเว็บหลัก 4 หน้า

| ไฟล์ | คืออะไร | ข้างในมี |
|---|---|---|
| **`erp.html`** | **หน้าแรกของทั้งระบบ** — ไม่ใช่โมดูลแยก แต่เป็นตัวครอบอีก 3 อันไว้ | การ์ด 6 โมดูล (ใช้ได้จริง 3) · ตัวเลขสรุปงานวันนี้ · ตั้งค่าผู้ใช้ + รหัส (Admin เท่านั้น) |
| **`po-mobile.html`** | PO Tracker **สำหรับมือถือ** — ตัวที่พนักงานใช้ทุกวัน | ภาพรวม · อัพเดทงาน · ➕ เพิ่ม PO · Archive · จัดการ |
| **`po-desktop.html`** | PO Tracker **สำหรับคอมพิวเตอร์** — ข้อมูลชุดเดียวกับมือถือ แค่จอใหญ่กว่า | Dashboard · รายการ PO · รายละเอียด PO · สร้าง PO · **QC ตรวจงาน** · Archive · จัดการ |
| **`stock.html`** | **คลังวัตถุดิบ** — วัสดุ 15 รายการตามรายงานกระทรวง | 📦 คลังปัจจุบัน · 🧾 รายวัน · 📈 รายเดือน · 🔐 ผู้ดูแล (ตั้งต้น/นับสต๊อก + สิทธิ์) |

### ไฟล์ประกอบ — ไม่ต้องเปิดเอง แต่ห้ามลบ

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเลือกอัตโนมัติ — เครื่องจอใหญ่+มีเมาส์ → ส่งไป PC · นอกนั้น → มือถือ |
| `sw.js` | ทำให้ติดตั้งเป็นแอปได้ + ใช้งานตอนเน็ตหลุดได้ |
| `manifest.json` | ไอคอน + ชื่อแอปตอนติดตั้งบนมือถือ |
| `po-tracker-gas.js` | ระบบเก่าสมัยใช้ Google Sheet — **เลิกใช้แล้ว เก็บไว้เผื่อย้อนดู** |

> ⚠️ **ห้ามเปลี่ยนชื่อไฟล์ 4 หน้าหลัก** — `manifest.json`, `sw.js` และ `index.html` อ้างชื่อพวกนี้อยู่
> เปลี่ยนเมื่อไหร่ = มือถือทุกเครื่องที่ติดตั้งแอปไว้แล้วจะเปิดไม่ได้ ต้องลบแล้วลงใหม่ทุกเครื่อง

## ⚡ 3 เรื่องที่ต้องรู้

1. **Supabase หลับเองถ้าไม่มีคนใช้นาน** (เกิดมาแล้ว 3 ครั้ง) — อาการคือเปิดแอปแล้วค้าง/โหลดไม่ขึ้น **ทุกเครื่องพร้อมกัน** แก้ได้โดยปลุกจากหน้า Supabase · ถ้าใช้ทุกวันปัญหานี้หายเอง
2. **แก้ไฟล์หน้าเว็บแล้วต้องเปลี่ยนเลขเวอร์ชันใน `sw.js` ด้วย** ไม่งั้นคนที่ติดตั้งแอปไว้จะยังได้ของเก่า
3. **สต๊อกยังไม่เคยใช้งานจริง** — ตัวเลขข้างในยังเป็นชุดทดลอง ต้องเดินนับของจริงแล้วกด "ตั้งต้นใหม่" ก่อน (ดู [`docs/STATUS.md`](docs/STATUS.md))
